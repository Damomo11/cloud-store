# 寻路补丁

云仓改用仓库内的 `vendor/mineflayer-pathfinder`，移植自 OlelaBot 的
`2.4.5-olela.18-r5-lossless`，同时接入其雪层、门/活板门、攀爬物和中空容器适配。
依赖通过 `file:` 安装，无需修改 `node_modules`；上游 MIT 许可证保留在 vendor 目录。

适用于大部分地形，包括雪山、室内通道等复杂地形，但依然不能保证完全可靠。
雪层会按实际碰撞高度和头顶净空规划，粉雪禁止进入；门口避免斜切，木门和栅栏门
可自动打开，活板门按路径坐标确认关闭。铁门、铁活板门以及不安全的带电/含水
活板门不会自动切换。脚手架和部分藤蔓可攀爬，不可执行的攀爬方向会被排除。

云仓继续禁止挖掘、放置方块和跑酷，保留有限下落限制并排除需要飞行的下降节点。没有接入 OlelaBot
的鞘翅、采集器或站点执行器。每个 bot 只安装一次控制器，方块、区块和重生事件
会清除地形缓存。脱困仅在有寻路目标时启动，避免干扰开窗取存；超时、无路径和停止
会沿用云仓的失败处理。

`npm test` 包含云仓集成测试及移植的地形、物理和 fork 回归测试；`npm run check`
也检查 vendor 源码。自动化测试使用 Minecraft 1.21.4 方块数据和本地物理模拟，
没有连接真实服务器。未加载区块、动态方块、服务器延迟和特殊物理仍需测试服验收。

来源：`kelemiao/OlelaNK-kelebot3` 的 `8b6dcdfd9bc6e229ca5519395869580d5252ea2d`，
主要对应 `node-bot/vendor/mineflayer-pathfinder`、`node-bot/src/path` 和
`node-bot/src/plugins/movement.js` 中的地形适配。后续修改应提交到这些本地源码，
不要直接补丁安装目录。
